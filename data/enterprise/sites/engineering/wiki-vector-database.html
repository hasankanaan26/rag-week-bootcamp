Vector database

A vector database is a database that stores data as high-dimensional vectors and retrieves it by similarity rather than by exact match. The vectors are produced by an embedding model that turns text, images, or audio into a list of numbers.

How it works

Each item is converted into an embedding and stored alongside its metadata. At query time the query is embedded the same way, and the database returns the stored vectors closest to it, typically using cosine similarity.

Use in retrieval-augmented generation

Vector databases are a core component of retrieval-augmented generation. The relevant chunks are retrieved by similarity and passed to a language model as context, which lets the model answer questions about private documents.

Which one does Acme use?

The platform team runs pgvector inside the main PostgreSQL cluster for production services. Chroma is used for prototypes and for this course.

  • Chroma, an embedded vector store used for prototypes.
  • FAISS, a similarity-search library from Meta.
  • pgvector, an extension that adds vector search to PostgreSQL.
